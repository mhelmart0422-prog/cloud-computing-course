Brief Overview

Amazon Web Services (AWS) is Amazon's cloud computing platform. AWS provides services for computing, storage, databases, networking, security, analytics, machine learning, and other cloud workloads. AWS launched in 2006.

Global Infrastructure

AWS organizes its infrastructure into geographic Regions and Availability Zones. Availability Zones are separate infrastructure locations within an AWS Region designed to provide isolation and improve availability and fault tolerance.

Cloud Management Console

The AWS Management Console is the web-based interface used to create, configure, monitor, and manage AWS resources.

Four Core Services
Category	AWS Service	Purpose
Compute	Amazon EC2	Virtual servers
Storage	Amazon S3	Object storage
Database	Amazon RDS	Managed relational databases
Identity	AWS IAM	Access and permissions

AWS's global infrastructure documentation lists EC2, S3, RDS, IAM and many other core services.

Three Advantages
Very broad selection of cloud services.
Large global infrastructure.
Strong scalability for startups and enterprises.

AWS describes itself as offering a broad and deep set of cloud capabilities, and its infrastructure spans many geographic regions.

Typical Enterprise Use Cases
