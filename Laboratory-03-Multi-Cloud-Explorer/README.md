# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory explores AWS, Microsoft Azure, and Google Cloud Platform.

## Cloud Platforms

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

## Linux Investigation

The KillerCoda Linux environment was examined using Linux commands to identify:

- Operating System
- CPU
- Memory
- Disk Space

## Cloud VM Options

| Provider | Service                |
| -------- | ---------------------- |
| AWS      | Amazon EC2             |
| Azure    | Azure Virtual Machines |
| GCP      | Compute Engine         |

The Linux server could be migrated to a virtual-machine service from any of the three major cloud providers. AWS could host it using Amazon EC2, Microsoft Azure could host it using Azure Virtual Machines, and Google Cloud could host it using Compute Engine. These services allow organizations to run Linux-based virtual machines in the cloud.
