Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides computing, storage, networking, databases, identity, AI, analytics, and other cloud services.

Azure became generally available as Windows Azure in 2010.

Global Infrastructure

Azure uses geographic regions containing physical datacenters and networking infrastructure. Many Azure regions provide Availability Zones for resilience, and some regions are paired for disaster recovery and geo-redundancy.

Cloud Management Console

The Azure Portal is the web interface used to create, manage, monitor, and organize Azure resources. Microsoft describes the portal as a consistent experience for building, deploying, and managing cloud resources.

Four Core Services
Category	Azure Service	Purpose
Compute	Azure Virtual Machines	Virtual servers
Storage	Azure Blob Storage	Object storage
Database	Azure SQL Database	Managed SQL database
Identity	Microsoft Entra ID	Identity and access management
Three Advantages
Excellent integration with Microsoft products.
Strong enterprise and hybrid-cloud capabilities.
Large worldwide infrastructure.

Azure's regional infrastructure and Microsoft ecosystem make it particularly suitable for organizations already using Microsoft technologies. Azure regions also provide multiple resiliency options.
