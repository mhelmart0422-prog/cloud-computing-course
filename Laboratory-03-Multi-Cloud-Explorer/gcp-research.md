Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides infrastructure, databases, storage, networking, analytics, AI/ML, and Kubernetes services.

Google launched App Engine in 2008, an early Google Cloud platform service.

Global Infrastructure

Google Cloud organizes infrastructure into regions and zones. A region contains multiple zones, and spreading workloads across zones or regions can improve resilience. Google also operates a global network connecting its cloud infrastructure.

Cloud Management Console

The Google Cloud Console is the web-based interface used to manage Google Cloud projects, resources, services, monitoring, billing, and configurations.
