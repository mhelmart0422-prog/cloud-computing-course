1. Cloud Services I Use

The three cloud services that I use regularly are Messenger, Facebook, and GCash. Messenger helps me communicate with my family, friends, and classmates through chats, voice calls, and video calls. Facebook allows me to connect with people, share updates, and stay informed about current events. GCash is useful for sending money, paying bills, buying mobile load, and making cashless payments. These cloud services make my daily activities faster, more convenient, and accessible from almost anywhere with an internet connection.

2. Identify the Models

Messenger – Service Model: Software as a Service (SaaS); Deployment Model: Public Cloud. It is a SaaS application because users access it online while Meta manages the software and infrastructure. It uses a public cloud because it is available to anyone with an account.
Facebook – Service Model: Software as a Service (SaaS); Deployment Model: Public Cloud. Users only need an internet connection to use the platform, while the provider handles maintenance and updates. It serves millions of users through a public cloud environment.
GCash – Service Model: Software as a Service (SaaS); Deployment Model: Public Cloud. It provides online financial services without requiring users to manage servers or software. It is publicly accessible but uses strong security measures to protect user accounts and transactions.

3. Git & GitHub for Cloud Projects

Version control is essential when working with cloud infrastructure because it records every change made to code, scripts, and configuration files. If a mistake happens, developers can easily return to a previous version without losing important work. GitHub supports collaboration by allowing multiple team members to work on the same project using branches and pull requests. It also keeps a complete history of changes, making it easier to review updates, resolve conflicts, and identify errors. Because of these features, GitHub helps teams build, manage, and maintain cloud projects more efficiently and reliably.
